# Community firmware: bug tracker

Bug reports, ideas and questions for an independent, unofficial firmware for
the Primus. This repository is the issue tracker only: it holds no source code
and no firmware downloads.

> **Unofficial firmware.** It is not made, endorsed or supported by WPM, so their
> support can't help with it.

## Is this the right place?

| You want to… | Go to |
| --- | --- |
| Report something that doesn't work on the community firmware | [New issue](https://github.com/o1y/coffee-firmware-community/issues/new/choose) |
| Suggest an idea or ask how something works | [Discussions](https://github.com/o1y/coffee-firmware-community/discussions) |
| Chat with other owners | [Discord](https://discord.gg/yDgpq5sf87) |
| Get official help with the original firmware, a hardware fault or your warranty | Your dealer, not here |

## Supported machines

The firmware has only been tested on EU versions of the Primus. It is not
compatible with the Slim or any other model or regional version.

## Getting the firmware

The firmware isn't available to the public yet. Issues and discussions asking
for a download or an invite will be closed with a link to this paragraph.

## Before you post

- **Search first.** Someone may already have reported it; add what you know to
  that issue instead.
- **One problem per issue**, in English.
- **Never post an invite code, or a photo of the activation QR code.**
- **A photo of the screen** is often the most useful thing you can attach.

## Security

Please don't open a public issue for a security problem. Use
[Report a vulnerability](https://github.com/o1y/coffee-firmware-community/security/advisories/new)
instead, which only the maintainer can read.
